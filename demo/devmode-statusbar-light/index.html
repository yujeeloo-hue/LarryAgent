四种状态对照（背景 #edf0f4）

现状accent 7% / 12% 静止 hover 选中 ghost
A 白药丸hover 白 / 选中白+accent 字 静止 hover 选中 ghost
B 淡蓝底10% / 16%+accent 字 静止 hover 选中 ghost
C 中性灰灰 7% / #dbe4ef 静止 hover 选中 ghost

A：与 Light 主题「白卡片 + 发丝边」的语言一致，选中态最明确（白底 + accent 字 + 1px accent 淡边 + 极轻投影），hover 只是白雾。
B：保留现在的 accent 色系，只把层级拉开（hover 10% / 选中 16% + accent 字 + 内描边）。
C：完全不用 accent，选中靠灰阶深浅，最安静但状态最弱。
